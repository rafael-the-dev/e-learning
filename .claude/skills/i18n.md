## Skills

### Internacionalização (i18n)

Todo o texto visível ao utilizador deve estar em **português de Portugal**. Nomes de variáveis, funções, tipos, chaves de objetos e valores de enum permanecem sempre em **inglês**.

#### Regra fundamental: separar valor de apresentação

Enum values são strings de domínio que viajam em URLs, query params, payloads de API, colunas de base de dados e schemas Zod. Nunca devem ser traduzidos. A tradução acontece **exclusivamente na camada de renderização**.

```tsx
// CORRETO — valor inglês, texto português
<SelectItem value="ACTIVE">Ativa</SelectItem>
<SelectItem value="TRIAL">Experimental</SelectItem>

// ERRADO — valor em português quebra query params e filtragem
<SelectItem value="Ativa">Ativa</SelectItem>
```

#### Onde aplicar tradução

- **Labels de colunas** — `header: "Estado"` (não `"Status"`)
- **Labels de campos de formulário** — `<Label>Morada</Label>`
- **Texto de botões e CTAs** — `"Guardar Alterações"`, `"Cancelar"`
- **Mensagens de toast** — `toast.success("Organização criada")`
- **Empty states e descrições** — `"Nenhum resultado encontrado."`
- **Títulos de diálogos de confirmação** — `"Eliminar Filial"`
- **Status badges** — via lookup table `STATUS_LABELS` indexada pelo enum value inglês:

```ts
const STATUS_LABELS: Record<string, string> = {
  ACTIVE: "Ativo",
  PENDING: "Pendente",
  SUSPENDED: "Suspenso",
  TRIAL: "Experimental",
  CANCELLED: "Cancelado",
  // ...
};
```

- **Mensagens de validação Zod** — `z.string().min(2, "O nome deve ter pelo menos 2 caracteres")`

#### O que nunca traduzir

- Nomes de variáveis, funções, interfaces, tipos TypeScript
- Chaves de objetos e schemas (`organizationId`, `createdAt`, `status`)
- Valores de `z.enum([...])` — `z.enum(["ACTIVE", "INACTIVE"])`
- Props `value` de `<SelectItem>`, `<RadioGroupItem>`, etc.
- Query params e route segments — `/organizations?status=ACTIVE`
- Valores guardados na base de dados

#### Datas e números

Usar sempre `toLocaleDateString("pt-PT")` e `toLocaleString("pt-PT")` para formatar datas e números visíveis ao utilizador.
